# Configure Code Review for this repository

## Problem Description

Tessl Code Review already runs on this repository. Nobody has ever configured
it, so it reviews with whatever it runs by default.

Configure it for this codebase. Decide what gets reviewed and what is left
alone, and tell us what you decided and why.

## Output Specification

- `plan.md` at the workspace root: which job this request is, which skill
  handles it, and why, in a few lines. Then what a review reads after your
  change, what it no longer reads, and anything you found that we should decide
  ourselves.
- Whatever files that job produces in the repository.
